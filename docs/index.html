Rugby League: Ultimate Footy

Privacy policy

Effective 22 October 2026. This page describes the Android app and the browser game of the same name, package com.ultimatefooty.meridian.

The game does not require an account. It does not show advertisements, charge for play, or send your save to the developer. Match data stays on the device.

Who is responsible

The game is published by Jye Fulton. Questions about this policy can be sent to jyefulton@gmail.com.

Data stored on the device

The game writes one save, and a backup of that save, in the app’s private storage. In a browser those keys are meridian-league-save and meridian-league-save-backup. On Android they live in the app’s WebView storage, which other apps cannot read.

The save can contain:

  • Settings you choose: difficulty, half length, clock speed, graphics, camera, handedness, volumes, and display options.
  • A Meridian Cup season: the fictional clubs, fixtures, and scores.
  • A career, if you start one: the name you type (or the suggested name), a playing position, a fictional club, attributes, and match totals.
  • A short history of finished matches and any achievements unlocked from those totals.

An in-progress match is not written into that save. Leaving a match or closing the app drops the live match.

Data that is not collected

The game does not collect your email address, phone number, contacts, photos, precise location, advertising identifier, or payment details. There is no account login, no analytics SDK, no crash-reporting service, and no advertising network.

The developer does not receive the save, the career name, or a device identifier from the app. There is no server for player accounts.

Network

The Android app is packaged with its own match code, artwork, and fonts. Playing a match does not contact the developer or a third-party analytics or advertising service. Opening this privacy page in a browser is an ordinary request to the site that hosts the page.

Children

The game does not ask for a date of birth and does not build a profile. A career name stays on the device. The game is not directed at collecting personal information from children.

How long it is kept

The save remains until you clear the app’s storage, uninstall the app, or clear the site data in the browser. Retiring a career inside the game removes the career from the save. There is no separate cloud copy to delete.

Sharing

The save is not sold, rented, or shared with advertisers or data brokers. The developer does not have a copy of it to hand to anyone else.

Changes

If this policy changes, the updated page will replace this one and the effective date at the top will change. The in-app privacy screen describes the same practices.
